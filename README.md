# 🎬 Movie Recommendation System

## 📌 Project Description
This is a simple Movie Recommendation System developed using Python, Flask, and Pandas. The application recommends movies based on the genre of the movie entered by the user.

## 🚀 Technologies Used
- Python
- Flask
- Pandas
- HTML
- CSS

## 📂 Project Structure
```
Movie-Recommendation-System/
│── app.py
│── model.py
│── Movies.csv
│── requirements.txt
│── README.md
└── templates/
    └── index.html
```

## ▶️ How to Run

1. Install the required libraries:

```
pip install flask pandas
```

2. Run the application:

```
python app.py
```

3. Open your browser and visit:

```
http://127.0.0.1:5000
```

## ✨ Features

- Recommend movies based on genre
- Simple user interface
- Built using Flask and Pandas
